# Lumin — AI Skin Intelligence

Lumin is a high-conversion web application and interactive diagnostic platform. Built with a focus on user acquisition, it leverages our **Clinical Radiance System** design language (soft teal `#016464`, warm peach `#fbd9c1`, clean pill geometry, and ambient shadows) to build trust and drive engagement.

## Overview

The platform serves as the primary entry point for the Lumin brand, featuring a seamless onboarding funnel that captures user data through a personalized skincare diagnostic quiz, paving the way for targeted product recommendations and community building.

**Core Stack:**
- **Frontend:** Next.js 14 (App Router), React, Tailwind CSS, TypeScript
- **Backend & Auth:** Supabase (PostgreSQL, Edge Functions)
- **Deployment:** Vercel
